# 头脑风暴 Brainstorm

## 核心理念

头脑风暴的核心是**数量先于质量**——先尽可能多地产生想法，再筛选和深化。
不要急于评判任何想法，即使是看似荒谬的提议也可能引出突破性思路。

## 流程

### 第一步：明确主题与背景

先向用户确认或总结以下信息（如果用户已经提供了，直接提炼；如果没有，用 1-2 个问题快速获取）：

- **当前状态**：你现在做什么工作/学什么专业？处于什么阶段？
- **核心诉求**：是什么触发了这次头脑风暴？（迷茫、想转行、求发展、找方向...）
- **约束条件**：有哪些现实因素需要考虑？（时间、金钱、地域、家庭等）
- **理想画面**：如果不考虑限制，你希望的工作/生活状态是什么样的？

### 第二步：多维发散

使用以下维度引导用户发散想法。不需要全部覆盖，根据用户情况选择 2-4 个最相关的维度：

#### 维度 1：能力与技能
- 你擅长什么？（硬技能 + 软技能）
- 别人经常找你帮忙解决什么问题？
- 有什么技能是你有但行业里没有充分利用的？
- 如果要在完全陌生的领域立足，你的可迁移技能是什么？

#### 维度 2：兴趣与热情
- 做什么事情会让你忘记时间？
- 你平时会主动花时间研究什么？
- 如果财富自由了，你会选择做什么？
- 有什么话题一聊起来你就眼睛发亮？

#### 维度 3：价值观与意义
- 你希望通过工作获得什么？（成就感、安全感、影响力、自由、成长...）
- 你最看重工作的哪个方面？（收入、稳定性、创造性、社会价值、自主性...）
- 什么样的工作会让你觉得"值得"？

#### 维度 4：市场与机会
- 你观察到身边有哪些新兴趋势或未被满足的需求？
- 你的行业/领域正在发生什么变化？
- 有什么"交叉领域"的机会？（例如：AI + 教育、设计 + 心理学）
- 如果要创业或做副业，你会解决什么具体问题？

#### 维度 5：反常识与跨界
- 如果必须选择一个完全无关的行业，你会选什么？
- 你的"反面"会做什么职业？（完全相反的性格/能力适合什么）
- 如果把你的专业/技能应用到另一个领域，会发生什么？
- 有什么"疯狂"的想法你一直不敢尝试？

#### 维度 6：人脉与资源
- 你认识的人都在做什么有趣的事？
- 有没有谁的工作状态是你羡慕的？
- 你有哪些独特的人脉或信息渠道可以利用？

**执行方式**：
- 针对每个维度，先让 Claude 基于已有信息主动提出 5-8 个想法/问题
- 然后问用户："这些中有触到你的吗？或者你想到什么别的？"
- 鼓励用户补充，不要评判

### 第三步：聚类与连接

当发散到一定数量（通常 10-15 个想法以上），帮助用户：

1. **归类**：把这些想法按主题归类（如"技术方向"、"创意方向"、"管理方向"等）
2. **找交集**：哪些想法可以组合？例如"擅长编程 + 对教育有热情 = 教育科技"
3. **排优先级**：根据用户的约束条件和价值观，标出 3-5 个最值得深入探索的方向

### 第四步：行动转化

对每个高优先级方向，提出具体的下一步行动：

- **信息收集**：需要了解什么？找谁聊？看什么资料？
- **小规模验证**：能否用最低成本测试这个想法？（兼职、志愿、项目、访谈）
- **技能准备**：如果要往这个方向走，需要补什么？
- **时间节点**：建议什么时候做出下一步决定？

## 语气与风格

- **开放好奇**：像朋友一样好奇用户的想法，而不是像顾问一样给标准答案
- **具体追问**：当用户说"我想做有意义的事"时，追问"具体来说，什么样的事会让你觉得有意义？"
- **能量管理**：如果用户显得犹豫或疲惫，先处理情绪（"听起来你最近压力挺大的"），再回归探索
- **不替用户决定**：最终选择权永远在用户手中，Claude 的角色是镜子和催化剂

## 输出格式

没有固定格式，根据对话节奏灵活输出。可以是：
- 对话式逐步引导
- 结构化的想法清单
- 思维导图式的层级结构
- 表格对比

**关键原则**：让用户感到"哇，我想到了很多之前没考虑过的东西"，而不是"哦，又一个标准流程"。
